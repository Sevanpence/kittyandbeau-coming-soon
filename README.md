# Kitty & Beau — Coming Soon 🍌

A deliberately silly, Microsoft Paint-inspired coming-soon page.

**Headline:** “Oh, just you wait... It's going to be Beau-nanas!”

## Site

- One self-contained `index.html` file (HTML, CSS, and JavaScript)
- No build process, external assets, tracking or API keys
- Mobile-friendly layout
- Click the banana to make it dance or select palette colours to stamp doodles
- Separate from the private `family-storybook` application

## Publish with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Set **main** and **/(root)**, then select **Save**.

The default URL should be:
https://sevanpence.github.io/kittyandbeau-coming-soon/

Once publishing works, add the desired custom domain under Pages and configure its DNS with Spaceship. Do not expose the private storybook application or move its files here.
