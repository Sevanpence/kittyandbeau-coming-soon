# Kitty & Beau — Coming Soon 🍌

A deliberately bad MS Paint-style drawing, with a big “Oh, just you wait... It's going to be Beau-nanas!” message.

The site is a single static `index.html` file: white background, clumsy colourful text, one silly banana doodle, no JavaScript, fonts, dependencies or user data.

GitHub Pages publishes `main` at `/(root)`. The primary custom domain is `kittyandbeau.com` (see `CNAME`); DNS is managed separately with Spaceship.

This public teaser is completely separate from the private `family-storybook` development repository.
